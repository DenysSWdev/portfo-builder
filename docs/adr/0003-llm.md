# ADR 0003: LLM — Anthropic, one provider behind an abstraction

**Status:** accepted, 2026-11-11

## Decision
- Starting provider: Anthropic API.
- A cheap Haiku-class model for project cards and posts; Sonnet for the chat agent. Model identifiers live in configuration.
- Access only through the `packages/core/llm` interface; no other code imports the provider SDK directly.
- Structured output through tool use with a JSON schema, Zod validation, one retry.
- Prompt caching for the stable system prefix.

## Reasons
- A provider comparison test was deliberately skipped; the abstraction makes switching cheap if quality or price disappoint.

## Consequences
- Per-user generation limits are required (D1 `llm_usage`).
- Repo content is untrusted input: see the security rules in `CLAUDE.md`.
