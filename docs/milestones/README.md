# Milestones

Take them one at a time, in order. A milestone is done only when **every** item of its Definition of done is met. Do not start the next one until the previous one is done.

## Applies to every milestone

This is a learning project (see `CLAUDE.md`), so every milestone also requires:
- [ ] Before coding: the plan, alternatives and trade-offs were explained to the owner and confirmed.
- [ ] Learning notes written in `docs/learning/mNN-<name>.md` following `docs/learning/README.md`.
- [ ] Any new architectural decision recorded as an ADR.
