# ADR 0004: Дані окремо від шаблону

**Статус:** ухвалено, 2026-11-11

## Рішення
Репо користувача містить лише структуровані дані (JSON + markdown з frontmatter) і асети. Шаблони живуть у `packages/templates` і рендерять ці дані. Агенти, редактор і пайплайн змінюють лише дані, ніколи HTML.

## Причини
- PR від пайплайна маленькі й зрозумілі (один файл проєкту).
- Шаблон можна змінити без перегенерації контенту.
- Дані валідуються схемою — це перевірка перед auto-merge.
- Inline-редактор відображає `data-field` у поле даних без парсингу HTML.
- Ручні правки захищені полем `editedFields`.
