# ADR 0001: Хостинг сайтів на Cloudflare (варіант B)

**Статус:** ухвалено, 2026-11-11

## Контекст
Розглядали два варіанти: (A) сайт у репо користувача + GitHub Pages; (B) репо користувача як сховище даних, хостинг наш.

## Рішення
B. Мультитенантний Worker віддає зібрані сайти з R2 за hostname; власні домени через Cloudflare for SaaS; прев'ю — окремі префікси в R2. Дані й зображення зберігаються в репо користувача.

## Причини
- GitHub Pages не має preview-деплоїв для PR — ключового кроку флоу.
- Менше кроків онбордингу (не треба вмикати Pages і налаштовувати DNS для піддомену).
- Контроль над збіркою, кешем, доменами; можливість платних фіч.
- Низька вартість: Workers Paid ($5/міс) з включеними запитами, R2 з безкоштовним рівнем без оплати трафіку, 100 custom hostnames безкоштовно, далі ~$0.10/міс за кожен (ціни на 2026-11; перевіряй актуальні).

## Наслідки
- Потрібен білд-раннер (див. `architecture.md`, відкриті питання).
- Окремий Pages-проєкт на користувача не використовуємо через ліміти акаунта.
- Експорт на GitHub Pages — можлива пізніша фіча; дані вже в репо, тож вона дешева.
