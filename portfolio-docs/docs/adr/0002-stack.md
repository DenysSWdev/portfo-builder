# ADR 0002: Стек — Astro + Hono на Cloudflare Workers + чистий TS

**Статус:** ухвалено, 2026-11-11

## Рішення
- TypeScript strict, монорепо на pnpm workspaces.
- **Astro** — шаблони сайтів (статична збірка) і UI застосунку (SSR на Workers). Один набір компонентів для сайту і редактора.
- **Hono** — API і вебхуки на Cloudflare Workers.
- **Чистий TS** — клієнтський скрипт редактора і Chrome-розширення.
- **Zod** — схеми даних; **Vitest** — тести.

## Причини
- Next.js завеликий для задачі; повністю без фреймворків — доведеться самим писати роутинг, middleware, сесії.
- Hono мінімальний і нативний для Workers; Astro генерує статику без JS за замовчуванням і вміє оптимізацію зображень.
- Відомі фреймворки дають агентам передбачувані патерни.
- Вся інфраструктура в одній екосистемі Cloudflare.
