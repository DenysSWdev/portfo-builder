# ADR 0003: LLM — Anthropic, один провайдер з абстракцією

**Статус:** ухвалено, 2026-11-11

## Рішення
- Провайдер на старті: Anthropic API.
- Дешева модель рівня Haiku — картки проєктів і пости; Sonnet — чат-агент. Ідентифікатори моделей — у конфігурації.
- Доступ лише через інтерфейс `packages/core/llm`; решта коду не імпортує SDK провайдера напряму.
- Структурований вивід через tool use з JSON-схемою, валідація Zod, один retry.
- Prompt caching для стабільного системного префікса.

## Причини
- Порівняльний тест провайдерів свідомо пропущено; абстракція робить заміну дешевою, якщо якість чи ціна не влаштують.

## Наслідки
- Потрібні ліміти генерацій на користувача (D1 `llm_usage`).
- Вміст репо — недовірений ввід: див. правила безпеки в `CLAUDE.md`.
