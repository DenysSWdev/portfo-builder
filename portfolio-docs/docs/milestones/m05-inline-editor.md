# M5: Inline-редактор

## Обсяг
- `apps/app` `/edit`: рендер шаблону користувача з `editable`, `contenteditable` на елементах з `data-field`, кнопки заміни зображень.
- Скрипт редактора на чистому TS: відстеження змін, очищення вставки до plain text, "Зберегти", "Опублікувати", "Скасувати".
- API: diff полів → застосування до даних → додавання в `editedFields` → коміт → PR → прев'ю.
- Завантаження зображень: перевірка типу, ресайз до ≤2000px, WebP, коміт в `assets/`.
- `?edit` на публічному сайті → редирект у редактор.
- Другий і третій шаблон у `packages/templates`.

## Definition of done
- [ ] Зміна `profile.title` в редакторі → PR, що змінює лише це поле, → прев'ю показує нове значення.
- [ ] Вставка HTML з іншого сайту зберігається як plain text; тест.
- [ ] Заміна аватара: файл 10+ МБ стискається до розміру за правилом і потрапляє в `assets/`.
- [ ] Редагування доступне лише власнику сайту; тест на чужий сайт.
- [ ] Публічний сайт не завантажує JS редактора.
- [ ] Усі шаблони мають однаковий набір `data-field` за `data-model.md`.
