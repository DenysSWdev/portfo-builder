# M2: Картки проєктів через LLM

## Мета
Перетворювати README на картку для портфоліо: що це, яку проблему вирішує, стек, демо.

## Обсяг
- `packages/core/llm`: інтерфейс `generateProjectCard(input) → ProjectCard`, реалізація через Anthropic SDK, моделі з конфігу, tool use з JSON-схемою, prompt caching системного промпту.
- Вхід: README, languages, topics, homepage, опис репо. README подається як дані в розмежованому блоці.
- Валідація Zod, один retry з помилкою валідації, далі — помилка.
- Злиття з існуючим файлом проєкту з урахуванням `editedFields`.
- CLI `generate` отримує прапор `--llm`.
- Стиль: стриманий, конкретний, мовою з `portfolio.config.json`; без маркетингових штампів і емодзі.

## Definition of done
- [ ] На 10 реальних README різної якості (порожній, суто технічний, хороший) генерація дає валідні картки; приклади збережено як фікстури.
- [ ] Порожній або майже порожній README дає коректну коротку картку, а не вигадані факти.
- [ ] Тест: README з prompt injection ("ignore previous instructions…") не змінює формат виводу і не додає сторонній контент.
- [ ] Тест: поля з `editedFields` не змінюються після регенерації.
- [ ] Жоден модуль поза `core/llm` не імпортує SDK Anthropic.
- [ ] API-ключ береться лише з env; відсутній ключ дає зрозумілу помилку.
