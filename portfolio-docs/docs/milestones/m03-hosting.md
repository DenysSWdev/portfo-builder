# M3: Хостинг на Cloudflare

## Передумова
Ухвалене рішення щодо білд-раннера (`architecture.md`, відкрите питання 1) → новий ADR.

## Обсяг
- `apps/site-server`: Worker, що за `Host` знаходить сайт (D1 + кеш KV) і віддає файли з R2 за розкладкою з `architecture.md`; 404-сторінка; кешування через Cache API.
- Білд-раннер: збірка сайту з теки/гілки даних → завантаження в `sites/<userId>/prod/` або `preview/<n>/`.
- Прев'ю-адреси `pr-<n>--username.preview.<домен>`.
- Інвалідація кешу після деплою.

## Definition of done
- [ ] Два тестові користувачі на різних піддоменах отримують кожен свій сайт.
- [ ] Прев'ю доступне за власною адресою і не впливає на прод.
- [ ] Після нового деплою прод показує нову версію без ручного очищення кешу.
- [ ] Невідомий hostname → 404, без витоку даних інших користувачів; тест.
- [ ] Шлях з `..` чи поза префіксом користувача не віддає чужі файли; тест.
- [ ] Новий ADR для білд-раннера додано в `docs/adr/`.
