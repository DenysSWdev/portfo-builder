# M9: Чат-агент

## Обсяг
- `core/llm`: `chatEdit` на Sonnet; агент має інструменти лише для читання поточних даних і пропозиції змін у вигляді diff полів.
- Застосування diff — звичайним кодом з валідацією схемою → PR → прев'ю (той самий шлях, що в M5).
- Чат у дашборді з показом запропонованого diff перед застосуванням.
- Зміни за прямою вказівкою користувача додають поле до `editedFields`.

## Definition of done
- [ ] "Перепиши опис проєкту X коротше" → diff лише поля цього проєкту → PR з прев'ю.
- [ ] Користувач бачить diff і підтверджує його до створення PR.
- [ ] Агент не має інструментів запису в репо; PR створює код після валідації; тест.
- [ ] Запит поза межами даних портфоліо отримує відмову з поясненням.
- [ ] Діалоги враховуються в лімітах `llm_usage`.
