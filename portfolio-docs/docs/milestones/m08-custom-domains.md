# M8: Власні домени

## Обсяг
- Дашборд: додати домен, інструкція з CNAME, статус перевірки й SSL.
- Інтеграція з Cloudflare for SaaS (custom hostnames API): створення, перевірка статусу, видалення.
- `site-server` обслуговує сайт за власним доменом так само, як за піддоменом.

## Definition of done
- [ ] Користувач підключає власний піддомен і бачить сайт по HTTPS.
- [ ] Статус (очікує DNS, перевірка, активний, помилка) видно в дашборді.
- [ ] Видалення домену прибирає custom hostname у Cloudflare.
- [ ] Один домен не можна прив'язати до двох користувачів; тест.
