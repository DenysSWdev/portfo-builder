# M7: Chrome-розширення

## Обсяг
- `apps/extension`: Manifest V3, Side Panel API, чистий TS.
- Авторизація через сторінку застосунку, токен у `chrome.storage`.
- Side Panel: чернетки (стан `draft`), копіювати, редагувати, "опубліковано".
- API застосунку для розширення: список чернеток, оновлення стану.

## Definition of done
- [ ] Side Panel відкривається на будь-якому сайті і показує чернетки поточного користувача.
- [ ] "Копіювати" кладе текст у буфер; "опубліковано" змінює стан у дашборді.
- [ ] Розширення не читає й не змінює DOM сторінок; дозволи в маніфесті мінімальні.
- [ ] Вихід із застосунку робить токен розширення недійсним.
