# M6: Чернетки постів

## Обсяг
- `core/llm`: `generatePost(input) → PostDraft` для подій "новий проєкт" і "новий реліз" (release notes + коміти між тегами).
- Пайплайн створює чернетку в `post_drafts` для цих подій; звичайні push пост не генерують.
- Дашборд: список чернеток, редагування, копіювати, "опубліковано", "відхилити", "перегенерувати".
- Варіанти довжини під мережу: довгий (LinkedIn), короткий (X).

## Definition of done
- [ ] Новий проєкт і новий реліз створюють по одній чернетці; push без релізу — жодної; тест.
- [ ] Пост містить посилання на проєкт на сайті портфоліо.
- [ ] Короткий варіант вкладається в ліміт символів X.
- [ ] Стиль відповідає `product.md`; приклади на 5 проєктах збережено як фікстури.
- [ ] Генерації постів враховуються в лімітах `llm_usage`.
